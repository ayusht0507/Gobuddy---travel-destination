GoBuddy 🌍✈️

Your Next Adventure Awaits!

GoBuddy is a travel inspiration and guide website built using simple HTML. It is designed for travelers who want to explore India’s cultural heritage, natural beauty, and adventure spots. The website highlights destinations, travel tips, and packages while offering easy contact options for visitors.

📖 Project Description

Travel planning can be overwhelming—finding destinations, learning travel terms, organizing essentials, and comparing packages. GoBuddy solves this by being a one-stop digital travel companion:

Showcasing top travel destinations in India.

Explaining common travel terms for beginners.

Providing practical travel tips to make journeys smoother.

Highlighting popular travel packages with pricing and duration.

Offering a Contact Us page for inquiries and personalized help.

This project is fully built with HTML only, making it lightweight and simple to run in any browser without additional dependencies.

🖥️ Pages Overview
1. index.html (Homepage)

The homepage serves as the central hub for exploration:

Navigation Bar → Links to Home, Destinations, Travel Tips, Packages, and Contact Us.

Explore Section → Inspiring tagline encouraging travel.

Top 5 Travel Destinations → Taj Mahal, Hawa Mahal, Leh-Ladakh, Varanasi, Goa Beaches.

Travel Terms → Glossary explaining Visa, Transit, Itinerary.

Popular Destinations with Images → Engaging visuals of top landmarks.

Travel Tips Section →

Packing Essentials (universal adapter, first aid, passport, etc.)

Pre-Travel Checklist (visa, insurance, inform bank).

Featured Packages Table → Price, duration, and highlights of curated packages like Golden Triangle Tour, Kerala Backwaters, Goa, Leh-Ladakh.

Footer → Contact link, copyright, and "Back to Top".

2. contact_us.html (Contact Page)

Contact form alternative with email, phone number, and address.

Easy navigation back to the homepage.

Clean layout encouraging users to reach out.

🚀 How to Run Locally

Download or clone the repository.

Make sure all .html files and images are in the same directory.

Open index.html in your preferred web browser.

Use navigation links to move between sections and pages.

No additional setup, frameworks, or installations are required.
